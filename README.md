# karas-abbreviations　(v 0.5)

KaraS配列用の略語辞書です。
KaraSの基本音節辞書と組み合わせて使うことで、動詞・形容詞・助動詞の活用、よく使う語、助詞の組み合わせを1ストロークで入力できます。

| 辞書 | 内容 |
| --- | --- |
| [`verb.json`](verb.json) | 動詞・形容詞・助動詞の活用 |
| [`abbreviation.json`](abbreviation.json) | 活用しない一般略語（こと・とき・こそあど言葉など） |
| [`particle.json`](particle.json) | 一文字助詞・二文字以上の助詞（「のが」「とは」「からも」など） |

## 導入

1. 上の3つのJSONファイルをダウンロードします。
2. Plover の辞書設定で、KaraSの基本音節辞書に加えて3つのJSONを追加します。

辞書を自分用に変更したい場合は、[カスタマイズ](#カスタマイズ生成スクリプト) を参照してください。

## ストロークの表記

この仕様書では、各キーを押す（■）・押さない（□）で表します。
各手は4キーで、表記は左から順に以下のキーに対応します。
仕様上の文字割り当ては、英語の標準的なStenographキーボードのものに対応しています。

| | 左手 | 親指 | 右手 |
| --- | --- | --- | --- |
| キー | `S K W R` | `A O E U` | `R B G S` |
| 表記例 | `□■■□` | `□■□□` | `□□□□` |

親指は `A O` が左手、`E U` が右手の親指です。
上の表記例は左手 `K W` と親指 `O` を押すストローク（`KWO-`）で、「おもう」が出力されます。

## 活用辞書（`verb.json`）

左手と右手の組み合わせで **語** を、親指で **活用形** を指定します。

```
左手（語）  ＋  右手（語のグループ）  ＋  親指（活用形）
```

例: 「思った」= 左手 `□■■□` ＋ 右手 `□□□□` ＋ 親指 `□□□■`

### 登録語

表の各マスは、その語の終止形（親指 `□■□□`）の出力です。

| 左手 ＼ 右手 | `□□□□` | `□■□■` | `□□■■` | `□■■■` | `■□■■` | `■□□■` |
| --- | --- | --- | --- | --- | --- | --- |
| `□□□□` |  | ない | いく | です |  | ある |
| `□□□■` | くる | はいけない※ | おく |  |  |  |
| `■□□□` | する | かもしれない※ | しまう |  | させる | される |
| `□■□□` | たい |  | ちゃう |  |  |  |
| `□□■□` | なる | のです | のだ |  |  | のである |
| `■■□□` | はずだ | ほしい |  |  |  |  |
| `□■■□` | おもう | もいい | もらう |  |  | いただく |
| `□□■■` | られる | らしい | くれる |  |  | くださる |
| `□■■■` |  | にちがいない※ | あげる |  |  | さしあげる |
| `■■■□` |  |  | じゃう |  |  |  |
| `■□□■` | べきだ |  |  |  |  |  |
| `□■□■` | だ |  |  |  | できる | である |
| `■■□■` | わかる | んです |  |  |  |  |

※ 終止形・ます形・た形・ました形のみ登録されています。

### 親指: 活用形

| 親指 | 活用形 | 例: 思う | 例: たい | 例: だ | 例: です |
| --- | --- | --- | --- | --- | --- |
| `■□□□` | て形 | おもって | たくて | で | でして |
| `□■□□` | 終止形 | おもう | たい | だ | です |
| `□□■□` | ない形 | おもわない | たくない | でない | — |
| `□□□■` | た形 | おもった | たかった | だった | でした |
| `□□■■` | なかった形 | おもわなかった | たくなかった | でなかった | — |
| `■■□□` | ます形 | おもいます | たいです | だ。 | です。 |
| `■□■□` | ません形 | おもいません | たくありません | だが | ですが |
| `■□□■` | ました形 | おもいました | たかったです | だろう | でしょう |
| `■□■■` | ませんでした形 | おもいませんでした | たくありませんでした | なのか | ですか |
| `□■■□` | 意向形 | おもおう | たかろ | — | — |
| `□■□■` | 連用形 | おもい | たく | では | でし |
| `■■□■` | 命令形 | おもえ | — | — | — |
| `■■■□` | 仮定形 | おもえば | たければ | なら | — |
| `□■■■` | 未然形 | おもわ | たかろ | だろ | でしょ |

- 形容詞（たい・ほしい など）の「ます形」「ました形」は、「〜です」「〜かったです」になります。
- 助動詞（だ・です・のだ・のです など）は活用形の名前どおりにならないものがあります。実際の出力は例の列を参照してください。

### 一般動詞の活用語尾

登録語以外の動詞は、語幹を基本音節で入力し、活用語尾をこのストロークで入力します。
左手で **行**、右手で **活用の種類** を指定し、親指で活用形を指定します（親指の割り当ては上の表と同じです）。
例外が複数あります。

例: 「書いた」= 「か」（基本音節）＋ 左手 `□□□■` ＋ 右手 `□■■■` ＋ 親指 `□□□■`

| 左手 ＼ 右手 | 行 | 五段 `□■■■` | 上一段 `■□■■` | 下一段 `■■□■` |
| --- | --- | --- | --- | --- |
| `□□□□` | あ行 | （登録語: です） | いる | える |
| `□□□■` | か行 | く | きる | ける |
| `■□□□` | さ行 | す | （登録語: させる） | せる |
| `□■□□` | た行 | つ | ちる | てる |
| `□□■□` | な行 | ぬ | にる | ねる |
| `■■□□` | は行 | — | ひる | へる |
| `□■■□` | ま行 | む | みる | める |
| `□□■■` | ら行 | る | りる | れる |
| `□■■■` | が行 | ぐ | ぎる | げる |
| `■■■□` | ざ行 | — | じる | ぜる |
| `■□□■` | ば行 | ぶ | びる | べる |
| `□■□■` | だ行 | — | （登録語: できる） | でる |
| `■■□■` | わ行 | う | — | — |

表の各マスは終止形（親指 `□■□□`）の出力です。

## 一般略語（`abbreviation.json`）

## 助詞（`particle.json`）

**一文字目** を左手＋右手（基本音節と同じ形）で、**二文字目** を親指で指定します。
親指だけを押すと、二文字目の助詞を一文字助詞として入力できます。

例: 「のが」= 左手 `□□■□` ＋ 右手 `□□■□`（の）＋ 親指 `■□■□`（が）

### 一文字目（左手＋右手）

| 一文字目 | 左手 | 右手 |
| --- | --- | --- |
| の | `□□■□` | `□□■□` |
| と | `□■□□` | `□□■□` |
| で | `□■□■` | `□□□■` |
| に | `□□■□` | `□■□□` |
| を | `■■□■` | `□□■□` |
| へ | `■■□□` | `□□□■` |
| て | `□■□□` | `□□□■` |
| だけ | `□■□■` | `■□□□` |
| から | `□□□■` | `■□□□` |
| など | `□□■□` | `■□□□` |
| まで | `□■■□` | `■□□□` |

| 二文字目（親指） | 親指のみ | の | と | で | に | を | へ | て | だけ | から | など | まで |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| が `■□■□` | が | のが | とが |  |  |  |  |  | だけが | からが | などが | までが |
| を `■□□■` | を | のを | とを |  |  |  |  |  | だけを | からを | などを | までを |
| で `□■■□` | で | ので | とで |  |  |  |  |  | だけで | からで | などで | までで |
| は `□■□■` | は | のは | とは | では | には |  | へは | ては | だけは | からは | などは | までは |
| も `■■■□` | も | のも | とも | でも | にも | をも | へも | ても | だけも | からも | なども | までも |
| に `■□■■` | に | のに |  |  |  |  |  |  | だけに | からに | などに | までに |

## カスタマイズ（生成スクリプト）

辞書の内容は `rules/` 以下のYAMLから生成しています。
語の追加やストロークの変更をしたい場合は、YAMLを編集してスクリプトを実行してください。

### 準備

Python 3.10以降と `PyYAML` が必要です。

```bash
pip install pyyaml
```

### 実行

```bash
python3 verb.py      # verb.json と abbreviation.json を生成
python3 particle.py  # particle.json を生成
```

### 設定ファイル

| ファイル | 内容 |
| --- | --- |
| `rules/common.yaml` | 親指と活用形の対応、左手と行の対応、右手と活用の種類の対応 |
| `rules/custom_rules.yaml` | 登録語（語幹・活用の種類・ストローク）と活用表 |
| `rules/abbreviations.yaml` | 一般略語（ストローク→語） |
| `rules/particle.yaml` | 助詞の一文字目・二文字目と、生成する組み合わせ |

- `custom_rules.yaml` で `allowed_kinds` を指定すると、必要な活用形だけを生成できます。空いたストロークに別の略語を割り当てることもできます。
- `particle.yaml` の `overrides` で特定の組み合わせの出力・ストロークを上書きでき、`additional_entries` で規則外の語を追加できます。
- 活用生成ロジックは `src/conjugators/`（`verb.py`, `adjective.py`, `auxiliary.py`）にあります。
